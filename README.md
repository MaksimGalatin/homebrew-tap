# CODE Eternal / PADAM NOCTURNE Homebrew Tap

Official Homebrew tap for **PADAM NOCTURNE** (`v0.8.0`, PADAM License 1.0).

## Install

```bash
brew tap MaksimGalatin/tap
brew install padam-nocturne
```

## Verify

```bash
padam --version
padam-mcp --help
```
